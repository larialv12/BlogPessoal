## 📖 Sobre o Projeto

O Blog Pessoal é uma API REST desenvolvida com Java, Spring Boot e MySQL. O sistema permite o gerenciamento de publicações por meio de três recursos principais: Usuários, Postagens e Temas, possibilitando operações de cadastro, consulta, atualização e exclusão de dados.

## Funcionalidades

- Cadastro de usuários
- Gerenciamento de postagens
- Organização das postagens por temas
- Consulta de dados via API REST
- Persistência de dados em banco MySQL
- Validação de dados

## Tecnologias

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Validation
- MySQL
- Maven
